# ShortlistIQ — AI-Powered Recruitment Platform

ShortlistIQ is an intelligent recruitment and candidate management platform designed for staffing firms to streamline resume screening, improve candidate-job matching, and simplify collaboration with clients.

The platform uses AI to analyze resumes against job requirements, identify relevant skills and experience, generate explainable candidate matching scores, and help recruiters create curated shortlists for clients.

## Key Features

- **AI Resume Screening:** Automatically extract and analyze information from candidate resumes.
- **Intelligent Candidate Matching:** Evaluate candidates against job-specific requirements.
- **Explainable AI Scoring:** Display matching skills, missing qualifications, and supporting resume evidence.
- **Recruiter Dashboard:** Manage job openings, candidates, and screening results.
- **Client Shortlist Portal:** Allow clients to review shortlisted candidates and provide feedback.
- **Secure Authentication:** Role-based access for recruiters and clients.
- **Human-in-the-Loop Review:** Recruiters retain control over screening decisions and shortlist approvals.

## Core Workflow

1. Recruiter creates a job opening with required qualifications.
2. Candidate resumes are uploaded and parsed.
3. AI analyzes resumes against the job requirements.
4. Recruiter reviews matching scores and supporting evidence.
5. Selected candidates are added to a shortlist.
6. Clients review the shortlist and provide feedback.

## Tech Stack

- Frontend: React, TypeScript
- Backend: Python, FastAPI
- Database: PostgreSQL
- AI: Large Language Model API
- Resume Parsing: PyMuPDF
- Authentication: JWT

## Project Objective

To build a practical AI-powered recruitment solution that reduces repetitive resume screening work, provides transparent candidate matching insights, and enables efficient collaboration between staffing firms and their clients.

**Note:** AI-generated scores are decision-support signals, not automated hiring decisions. Recruiters remain responsible for reviewing candidates.
